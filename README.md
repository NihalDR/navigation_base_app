# navigation_base_app - flutter

A beauitifull customized nested animation in screen navigation.

✔️ Sound NullSafety

## Getting Started

To run this project, ensure you have [Flutter](https://docs.flutter.dev/get-started/install) installed on your system.

1. Clone the repository and navigate to the project directory:
   ```bash
   cd beautiful_navigation_nested_animation_transition-master
   ```
2. Install the required dependencies:
   ```bash
   flutter pub get
   ```
3. Run the application:
   ```bash
   flutter run
   ```
